# Changelog

All notable changes to this project will be documented in this file.

## v0.2.0

- Added GitHub Actions workflow for automated test runs.
- Added Docker support for easier local deployment.
- Added contribution guidelines for issues and pull requests.
- Added security reporting guidance for upload and FFmpeg-related issues.
- Expanded setup, Docker, troubleshooting, and maintenance documentation.

## v0.1.0

- First standalone open-source release.
- Added local FastAPI app and static browser UI.
- Added video upload, clip selection, crop controls, and GIF download.
- Added FFmpeg palette-based GIF conversion with fallback compression.
- Added focused API and converter tests.
